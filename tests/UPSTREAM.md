## Adaptations and limits

- Golden struct bytes were derived by hand from upstream data and encoding rules. They were not generated by this library or captured from a running C++ serializer.
- C++ chained IOBuf cases become contiguous Uint8Array subview and truncated-prefix cases. This library has no streaming transport.
- Rust container tests use native JS collections; float inputs are rounded with Math.fround for f32 expectations. Negative zero is added. Floating-point byte vectors independently check endianness.
- Go malformed payloads are decoded with an empty schema to exercise unknown-field skipping; the generated Go MyTestStruct and Go error classes are not ported.
- Local cases add fixed integer/container bytes, malformed input, depth limits and encoder validation.
- We do not run the full upstream C++/Rust/Go suites: they need their runtimes, Folly, generated types or transport APIs. RPC envelopes, chained transport implementations and multi-GB allocations are not supported test targets here.

Run offline after dependency installation:

```sh
bun test
bun run check
```
